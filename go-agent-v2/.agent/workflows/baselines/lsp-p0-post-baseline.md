# LSP P0 Post Baseline

## Scope
- Dynamic tools expose merged LSP surface only.
- Unavailable LSP mode exposes only `lsp_grep` schema.
- Diff capture trigger uses `lsp_file` with `action=change` and `persist_to_disk=true`.

## Tool Set (Post)
- `lsp_file`
- `lsp_inspect`
- `lsp_xref`
- `lsp_grep`
- `lsp_structure`
- `lsp_edit`
- `lsp_completion`
