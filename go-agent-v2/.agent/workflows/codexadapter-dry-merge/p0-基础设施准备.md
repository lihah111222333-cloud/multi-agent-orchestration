将 `adapter_client.go`(92L) 的 `requireClient` + 7 个 client 委托方法合入 `adapter.go`。

### 2. 扩展 `normalizeDeps`

- `requireThreadID(caller, threadID string) (string, error)`

### 7. 创建功能等价契约基线（供 P5 对比）

```bash
BASE=.agent/workflows/codexadapter-dry-merge/baseline
```
