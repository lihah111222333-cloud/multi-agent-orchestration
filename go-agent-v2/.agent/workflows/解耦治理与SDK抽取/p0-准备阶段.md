## 执行步骤

// turbo-all

1. 创建 `internal/tools/types_sdk.go`
   ```go
   package tools

   import "time"

   // CodeRunRequest 代码执行请求
   type CodeRunRequest struct {
       Mode     string
       Language string
       Code     string
       Command  string
       TestFunc string
       TestPkg  string
       AutoWrap bool
       WorkDir  string
       Timeout  time.Duration
   }

   // CodeRunResult 代码执行结果
   type CodeRunResult struct {
       ExitCode int
       Output   string
       Duration time.Duration
   }

   // （其余 DTO 按需定义）
   ```

2. 在 `internal/tools/providers.go` **追加**行为接口
   ```go
   import "context"

   // CodeExecRunner abstracts code execution.
   type CodeExecRunner interface {
       Run(ctx context.Context, req CodeRunRequest) (*CodeRunResult, error)
   }
   // ...其余接口见本目录 p1-tools接口化.md 的执行步骤 1。
   // 约束：行为接口必须可映射到现有实现，禁止先发明底层不存在的方法名。
   ```

3. 创建 `internal/difftracker/emitter.go`
   ```go
   package difftracker

       Tool          string

   type DiffEmitter func(result DiffResult)
   type WorkDirResolver func(agentID string) string
   ```
