# P1.6: bus 解耦

> **⚡ 可并行** — 与 P1、P1.5、P2 同时执行（第一波）

## 概况

| 指标 | 值 |
|------|-----|
| 包路径 | `internal/bus/` |
| 有效行数 | 590 |
| 文件数 | 4 个 prod + 1 个 test |
| 当前耦合点 | `router.go` 直接依赖 `internal/codex`（`Client` + `Event`） |
| 当前依赖方向 | `internal/bus/router.go` → `internal/codex`（单向） |
| discovery 现状 | `internal/discovery` 当前为零 internal 依赖接口包，可先保留 |

- [ ] P0 准备阶段已完成

- `internal/bus/router_test.go`（新增）— 为路由行为补回归测试（事件分流、连接缓存、清理）

### 禁止触碰的文件 ⚠️

- `internal/tools/*` (P1 负责)
- `internal/tooladapter/*` (P1 负责)
- `internal/difftracker/*` (P1.5 负责)
- `internal/lsp/*` (P2 负责)
- `internal/codex/*` (P5/P7 负责，本 phase 只读不改)

## 耦合分析

### router.go 当前耦合

```go
// 1. 类型别名 — 依赖 discovery
type AgentDiscoverer = discovery.Discoverer
type AgentEndpoint = discovery.RunningAgent

// 2. 字段 — 依赖 codex.Client
clients    map[string]*codex.Client

// 3. 方法 — 使用 codex 事件类型和常量
func (r *AgentRouter) PublishAgentEvent(agentID string, event codex.Event) { ... }
func (r *AgentRouter) getOrCreateClient(threadID string, port int) *codex.Client { ... }
```

### 解耦目标（与现有实现可映射）


> 事件常量统一引用 `agentcore.Event*`，避免复制字符串常量导致漂移。

## 执行步骤

// turbo-all

1. 在 `bus/bus.go` 或新建 `bus/types.go` 定义：
   - `AgentClient` interface（签名必须与现有 `codex.Client` 可映射）
   - `AgentClientFactory` func type
   - `AgentEvent`（建议直接 alias `agentcore.Event`）

2. 修改 `bus/router.go`：
   - 删除 `import "internal/codex"`
   - `*codex.Client` → `AgentClient`（factory 注入）
   - `codex.Event` → `AgentEvent`
   - `codex.EventXxx` 常量 → `agentcore.EventXxx`
   - 更新构造函数签名并同步更新调用点（当前仓库无外部调用点，仍需保持可编译）

3. `discovery` 依赖评估：
   - 当前 `internal/discovery` 仅含接口和 DTO，可保留
   - 若后续引入传递耦合，再另开 phase 处理，不在本 phase 扩散改动

4. 保持 `internal/codex/*` 只读，做方向校验而非改代码：
   ```bash
   rg -n '"github.com/multi-agent/go-agent-v2/internal/codex"' internal/bus/*.go
   # 期望: 无输出

   rg -n '"github.com/multi-agent/go-agent-v2/internal/bus"' internal/codex/*.go
   # 期望: 无输出
   ```

5. 新增 `internal/bus/router_test.go` 覆盖关键行为：
   - `PublishAgentEvent` 的 subtopic 分流（output/exec/error/lifecycle）
   - `getOrCreateClient` 的缓存复用（`Running()==true` 复用）
   - `CleanupStale` 会清理 `Running()==false` 客户端

6. 验证
   ```bash
   go build ./internal/bus/...
   go test ./internal/bus/...
   go build ./...
   ```
