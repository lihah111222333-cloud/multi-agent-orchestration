### 步骤 1: codex events 表驱动

1. 在 `client_appserver_events.go` 中提取 `trackTurnLifecycle` 为表驱动:
   ```go
   var turnLifecycleHandlers = map[string]func(c *AppServerClient, event Event, method string){
       EventTurnStarted:      handleTurnStarted,
       EventTurnComplete:     handleTurnTerminal,
       "turn_aborted":        handleTurnTerminal,
       EventIdle:             handleTurnTerminal,
       EventError:            handleTurnTerminal,
       EventShutdownComplete: handleTurnTerminal,
       EventStreamError:      handleStreamError,
   }
   ```

2. 提取各 handler 为独立小函数（从 switch case 提取）

3. 精简重复的日志调用 — 抽 `logTurnEvent` helper

4. 验证: `go test ./pkg/codexsdk/codex/...`
